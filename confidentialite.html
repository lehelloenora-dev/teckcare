Politique de confidentialité

Ce que ce site enregistre, pourquoi, et comment garder la main.

Ce que le site enregistre

Toutes les données ci-dessous sont enregistrées uniquement dans votre navigateur (stockage local). Dans ce prototype, elles ne sont envoyées à aucun serveur et aucun e-mail n’est envoyé.

  • Panier : articles, quantités et code de parrainage saisi.
  • Commande : articles, montants, coordonnées et adresse de livraison, source déclarée (facultative). Aucune donnée bancaire n’est demandée : le paiement est simulé.
  • Profil du chiot : prénom (facultatif), variété (facultative), âge, poids, réponses sur la silhouette et habitudes de sortie, ration estimée.
  • Rappel de fin de sac : format, date d’ouverture, ration et, si vous choisissez l’e-mail, votre adresse avec votre consentement (distinct de celui du club).
  • Club et balades : e-mail, prénom du teckel (facultatif), centres d’intérêt, code postal si vous choisissez les rencontres, inscriptions aux balades.
  • Rendez-vous vétérinaires : clinique choisie, motif, date, créneau, coordonnées saisies. Rien n’est transmis à une clinique.
  • Parrainage : votre code personnel, créé après votre première commande.

Pendant la visite seulement (stockage de session) : les paramètres de campagne présents dans l’adresse (UTM).

Pour tout effacer, videz les données du site dans les réglages de votre navigateur.

Services externes

La carte de « Mon véto » peut charger un plan des rues (CARTO, données OpenStreetMap) ; pour une ville absente de nos données, la recherche peut interroger l’API publique Découpage administratif (geo.api.gouv.fr) avec le nom saisi. Le bouton Google Agenda ouvre Google Agenda dans un nouvel onglet.

Mesure d’audience

Aucun outil de mesure d’audience n’est actif sur ce site : aucun identifiant n’est configuré, rien n’est envoyé.
